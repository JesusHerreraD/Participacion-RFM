03 Ingeniería de Datos & Remapeo Probabilístico

El Problema del Dataset Real y la Simulación de Recurrencia

Durante la fase de exploración (EDA) surge una anomalía crítica: el dataset real de Kaggle contiene 1,000 transacciones con exactamente 1,000 clientes distintos. Es decir: df.customer_id.value_counts().max() == 1. Sin clientes recurrentes, la dimensión Frecuencia (F) colapsa en una constante (1), anulando cualquier modelo RFM.

warning Diagnóstico: Colapso de Varianza en F

Cada cliente tiene Frequency = 1. Calcular cuantiles sobre una variable invariante genera un único cuantil idéntico para el 100% de la población, impidiendo diferenciar compradores leales de transacciones esporádicas.

df['customer_id'].nunique() / len(df) == 1.0 # 100% registros unívocos
psychology Solución: Muestreo con Reposición (Seed 101)

Se simula un universo cerrado de 500 clientes potenciales mediante np.random.randint(0, 500, size=1000). Al asignar 1,000 compras sobre 500 identidades, se induce una distribución de Poisson realista con clientes de 1 hasta 6 compras recurrentes.

np.random.seed(101) # Garantiza reproducibilidad exacta
code_blocks pipeline_preprocessing_and_simulation.py 
# 1. Estandarización de nombres de columnas (Clean Code PEP8)
df.columns = df.columns.str.lower().str.replace(' ', '_')

# 2. Conversión estricta de formato temporal
df['date'] = pd.to_datetime(df['date'])

# 3. Inyección sintética de recurrencia mediante semilla pseudoaleatoria
np.random.seed(101)
random_cust_ids = np.random.randint(0, 500, size=len(df))

# 4. Formateo a código de cliente estándar CUST000
df['customer_id'] = [f"CUST{str(i).zfill(3)}" for i in random_cust_ids]

A partir del dataset transaccional con clientes recurrentes, se fija la fecha pivote de análisis max_date = df['date'].max() + dt.timedelta(days=1) para evaluar cuántos días han transcurrido desde la última interacción de cada cliente.

swap_vertical_circle ¿Por qué el Scoring de Recencia se Invierte?

En analítica de retención, menos días transcurridos significa un cliente más activo y receptivo. Por tanto, la función asigna la máxima puntuación (5) a los valores numéricos más bajos de Recency:

RScore(días, quantiles) x ≤ Q1 → Score: 5 (Más reciente) x ≤ Q2 → Score: 4 x ≤ Q3 → Score: 3 x > Q4 → Score: 1 (Muy inactivo)
FMScore(val, quantiles) x ≤ Q1 → Score: 1 (Mínimo aporte) x ≤ Q2 → Score: 2 x ≤ Q3 → Score: 3 x > Q4 → Score: 5 (Aporte máximo)
lightbulb Resultado: En las tres dimensiones, 5 siempre representa la excelencia comercial.
